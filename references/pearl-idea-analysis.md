# Pearl Idea — Reference Analysis (recruit.pearl-idea.co.jp)

Sumber: sesi brainstorming 2026-08-14. Analisis penuh + TODO: `~/projects/digital-portfolio/reference/pearl-idea/` (HTML, CSS, images) + Obsidian `Projects/digital-portfolio-pearl-analysis.md`.

## Kenapa Pearl

Warmth feelings — storytelling manusia, understated UI. BUKAN clone — design mungkin ubah, warmth kekal.

## Design System Pearl (asal)

- Palette warm editorial: bg #EEE7D9/#F5F2E9 (cream), primary #BBA764 (gold), secondary #EA6182 (rose), #E35D3C (terracotta), text #2A2928
- Typography: Libre Baskerville (serif editorial) + Albert Sans + IBM Plex Sans JP
- Sizes: H1=80px, H2=48px, body line-height 1.8

## Kunci Warmth (dari Pearl — KEKAL)

1. Real stories (initials, tahun, cerita peribadi)
2. Serif editorial typography
3. Candid photography
4. Understated UI (text-link buttons, underline animation)

## Yang DITOLAK untuk Ayah

- Cream palette — vibe artisan Jepun, tak padan finance/ops. → Navy + gold (trust & finance).
- Rose/terracotta accents → gold je sebagai bridge warmth + finance.

## Animations (pilihan, jangan overdo)

- Lenis smooth scroll
- Parallax images
- Horizontal marquee (memories)
- Sticky columns
- SVG mask stroke animation

> ⚠️ Rule ayah: NO glassmorphism, NO backdrop-blur, NO AI-looking effects. Reference-first design — copy real sites.
