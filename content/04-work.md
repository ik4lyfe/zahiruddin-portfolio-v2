# Work — Internal Projects & Freelance Case Studies

> RAW CONTENT — GOLD section. Frame: "Internal Digital Transformation Projects", BUKAN freelance.
> Cerita semua "manual → auto" — digital transformation dalam organisasi.

## PROJECT 1: eFOPRINS (Electronic Food Premise Inspection)

- **Masalah:** Laporan pemeriksaan lapangan manual (carbonised form). Bawa beg berat buku borang. Laporan per premis compile manual — makan seharian/bawak esok. Team TAK SUKA check banyak kedai sebab banyak premis = banyak laporan.
- **Apa dibina:** End-to-end system, stack simple, zero cost. Borang manual → Google Form. Laporan auto-generate via Autocrat. Email auto via Autocrat.
- **Siapa guna:** Unit Kesihatan Awam, Pusat Kesihatan UiTM (~5 orang).
- **Hasil:** Laporan pemeriksaan 1-2 hari → beberapa click. Data real-time, zero manual compile.

## PROJECT 2: eSAFE (Aedes Survey) — Dengue Prevention

- **Masalah:** Macam eFOPRINS — aedes survey manual di semua bangunan UiTM, laporan compile manual.
- **Apa dibina:** Sistem sama (Google Form + Autocrat) untuk aedes survey.
- **Siapa guna:** Unit Kesihatan Awam + komuniti D'Buster Team (jawatankuasa kawalan & pencegahan demam denggi peringkat organisasi). Beyond jabatan sendiri.
- **Hasil:** Survey & laporan auto, data real-time.

## PROJECT 3: UiTM Public Health Dashboard (Google Data Studio) — HERO STORY

- **Origin story:** Bos nak "eagle eye overview" macam peta besar kat balai polis — pin point lokasi premis makanan, tarik benang, update manual. Ayah CADANGKAN dashboard digital sebagai ganti.
- **Masalah:** Laporan lapangan manual. Laporan bulanan/tahunan compile manual 2-3 hari. Meeting bawa fail bertingkat.
- **Apa dibina:** Interactive dashboard — data connect auto, update real-time, laporan auto-generate.
- **Siapa guna:** Unit Kesihatan Awam, Pusat Kesihatan UiTM (~5 orang).
- **Hasil:** Laporan bulanan 2-3 hari → beberapa click. Data real-time, zero manual compile.
- **Impact:** Bos SANGAT bangga — jual cerita kejayaan hampir semua tempat. Pengarah puji, jadikan contoh dalam mesyuarat pengurusan, WAJIBKAN semua unit ada dashboard — "kalau tak reti, belajar dengan Zahiruddin". Jabatan organise 2 siri bengkel, jemput ayah mengajar & fasilitate.

## PROJECT 4: Centralized Digital Hub (Linktree)

- **Masalah:** Banyak digital project — pening nak cari link. Team kena hafal banyak URL.
- **Apa dibina:** Satu platform centralize — semua access dalam satu domain URL: submit form, tgk laporan, tgk dashboard.
- **Siapa guna:** Seluruh team + komuniti.
- **Hasil:** Team cuma hafal 1 domain URL. Sistem thinking — bukan buat system je, fikir pasal adoption & usability.

## PROJECT 5: UKA Official Website (Unit Kesihatan Awam)

- **Masalah:** Unit tak nampak visibility — takde web presence tersendiri.
- **Apa dibina:** Website unit — tiru design & format website rasmi UiTM (ikut standard institusi). Bos setuju, sangat suka.
- **Siapa guna:** Unit Kesihatan Awam, Pusat Kesihatan UiTM.
- **Hasil:** Terus jadi website rasmi unit — satu-satunya unit di Pusat Kesihatan UiTM yang ada website tersendiri, dengan domain rasmi uitm. Bukti kerja memenuhi standard institusi.

## Precedent Penting

- Website UKA sengaja **tiru design & format website rasmi UiTM** → bos setuju & suka. Ayah faham kuasa mirroring institusi untuk stakeholder buy-in.
- Dashboard bermula dari peta fizikal atas permintaan bos → ayah cadangkan digital. Pattern: dengar keperluan stakeholder, tawarkan versi lebih baik.
